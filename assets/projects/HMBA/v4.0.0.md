# ATACseq Marmoset Subcortex

**ID:** hmba-atacseq-marmoset-subcortex

![ATACseq Marmoset Subcortex screenshot](/assets/papers/HMBAViewers/ATAC_Viewer.webm)

**Project:** [HMBA:Basal Ganglia ATACseq + Spatial Tx Marmoset Subcortex](https://allen-hmba-releases.s3.us-west-2.amazonaws.com/cytosplore/Release/BasalGanglia_PublicationPackage/BGPackageRelease_2026_ATACseq_Marmoset_Subcortex.mv) in the [Cytosplore Viewer](/#get)

**Contact:** Chang Li
**Email:** Cytosplore_RADI@lumc.nl

**Description:** This viewer enables interactive exploration of ATAC-seq and RNA-seq data, linking peaks to genes via matching annotations. ATAC-seq peaks and RNA-seq genes are projected onto the spatial domain based on matching annotations. RNA-seq genes with spatial patterns similar to a selected ATAC-seq peak (and vice versa) can be identified. The top cell types associated with these features can be inspected and displayed on the spatial map and the RNA-seq UMAP.

- [Publication: Cell](https://doi.org/10.1016/j.cell.2026.10.007)
